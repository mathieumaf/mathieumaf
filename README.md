# Mathieu Mafille

I build and run AI products at [Digilac](https://digilac.ch) in Neuchâtel, Switzerland.

- [simap-mcp](https://github.com/Digilac/simap-mcp): an MCP server that lets AI assistants search Swiss public tenders.
- [Detour](https://github.com/mathieumaf/detour): a proxy-switching extension for Chrome and Firefox.
- [Vidra](https://github.com/mathieumaf/vidra): a local video converter for macOS, built on FFmpeg.

I mostly write TypeScript and Python, with some Rust, and I like running the servers my code lives on.
